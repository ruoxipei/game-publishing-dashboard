# 休闲游戏发行看板

五款游戏的发行总览与产品贡献分析，以及 Arrows、Sola Mahjong、8 Ball Pool 的渠道对比。

统计范围：2026-01-01 至 2026-09-20；新增三款的 overall DAU、IAP 更新至完整统计期。8 Ball Pool 和 Subway Surfers 提供完整 IAA；Arrow Puzzle 保留旧表已有 IAA，其余日期留空。8 Ball Pool 经营新进和国家明细截至 9/13，国家 DAU 与 overall 的差额列入 Others。8 Ball Pool 月度 UA 新安装、美元投入及 ROAS1/7 独立保留，9 月截至 9/20；UA 新安装不与经营新进相加。8 Ball Pool 留存原表日期为回访日：Dn 回移 n 天至新进日，月度按对应新进人数加权；缺少留存或对应新进的日期不参与加权。月度 UA 数据仅用于可精确匹配的统计窗口，不拆分至每日；经营收入与 UA 回收分别处理。具体指标范围见页面备注。

总览展示期间新进、日均活跃、期间收入、UA投入和 ARPDAU。Subway Surfers 不做 UA；Arrow Puzzle 暂无 UA 数据。

渠道分析支持同产品的渠道效果对比、ROAS / UA CPI 时间趋势、同渠道的跨产品对比与区域筛选。区域分析来自产品×渠道×国家的联合明细，沿用现有区域映射；8 Ball Pool 未提供渠道留存，保持为空。

看板采用六个独立栏目页签；产品贡献、渠道分析、产品深看按主题分层。各模块新增本期变化摘要，支持最近完整月对前月、最近 7 天对前 7 天，可导出 Markdown 复盘摘要。变化指标仅纳入两期都完整的产品；ARPDAU 使用收入与活跃共同完整的产品，回收及留存按源数据截止日检查批次成熟度。摘要列出比较日期与可比范围，不将缺失或尚未成熟的数据解释为下降。

静态页面，无外部数据请求。原始 Excel 与本地分析文件不在发布包内。
